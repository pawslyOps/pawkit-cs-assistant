# Paw-paw (Pawkit CS Assistant)

Internal page for the Pawkit Customer Service team: answers from Pawkit's SOPs and team notices, plus a read-only customer lookup.

- Address: https://cs-assistant.pawkit.sg (GitHub Pages from `main` /docs)
- The page holds no SOP text and no passcodes. Everything runs through the Pawkit Apps Script web app (project owned by vinceamandac001; `API` in docs/index.html).
- Custom domain: needs one Wix DNS record, `CNAME cs-assistant -> pawslyops.github.io`. After it resolves, move `CNAME.pending` to `docs/CNAME`, push, and set the Pages domain.
